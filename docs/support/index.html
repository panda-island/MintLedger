常見問題

為什麼安裝新版後看不到舊資料？

若安裝的是不同 Bundle ID 的版本，iOS 會視為另一個 App。請先在舊版匯出 .mintledger 備份，再於新版使用「從備份還原」。

iCloud 備份沒有出現

請確認 iPhone 已登入 iCloud、iCloud Drive 已開啟，且 iCloud 尚有可用空間。雲端備份不需要購買。

Widget 與 App 數字不同

請先開啟 MintLedger 一次，再長按 Widget 選擇重新整理；正式版需要主 App 與 Widget 的描述檔都包含相同 App Group。

功能需要付費嗎？

不需要。MintLedger 的記帳、小工具、捷徑、本機備份與 iCloud 雲端備份都可免費使用。

版本與下載

原始碼、版本說明與測試用 Release 可在公開專案查看。App Store 正式版上架後，請優先從 App Store 安裝。
